# שם הפרויקט

תוכנית Python לניהול וארגון המערכת. התוכנית כוללת תפריט טקסטואלי אינטראקטיבי, לוגיקה מרכזית לחישוב ודירוג, ובדיקות אוטומטיות.

---

## 🛠️ דרישות סביבה והרצה

* **גרסת Python שנבדקה:** Python 3.10 ומעלה (שימוש בספרייה הסטנדרטית בלבד, ללא צורך בהתקנת חבילות חיצוניות).

### פקודת הרצה:
```bash
python main.py
```
*(במערכות Windows שבהן הפקודה `python` אינה מוגדרת, יש להשתמש ב-`py main.py`)*

### הרצת הבדיקות האוטומטיות:
```bash
python -m unittest discover -s tests -v
```

---

## ✨ 3 היכולות העיקריות במערכת

1. **הוספת רשומה / קלט חדש:**
   * קליטת נתונים חדשים למערכת תוך אימות תקינות הקלט (דחיית קלט ריק, ערכים שליליים או סוג נתונים לא תואם).
2. **חיפוש וסינון במאגר:**
   * איתור פריטים/נתונים מתוך המאגר הקיים לפי קריטריונים מוגדרים.
3. **לוגיקה מרכזית (חישוב / דירוג / המלצה):**
   * הרצת אלגוריתם הליבה של המערכת המבצע חישוב שקוף, דירוג לפי העדפות/תוצאות ושבירת שוויון במקרה של ניקוד זהה.

---

## ⚠️ מגבלות ידועות

* **זיכרון ריצה:** הנתונים נשמרים בזיכרון הריצה (In-Memory) לאורך זמן הפעלת התוכנית.
* **ממשק משתמש:** הממשק הינו טקסטואלי בלבד (CLI) הפועל דרך הטרמינל.
* **עבודה לא מקוונת:** התוכנית פועלת באופן מקומי ואינה תלויה בחיבור לרשת או בשירותי ענן.
