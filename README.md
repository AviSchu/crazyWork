# 🚀 שם הפרויקט

תוכנית Python אינטראקטיבית לניהול, חישוב וארגון נתונים. המערכת מספקת ממשק משתמש טקסטואלי נוח (CLI), מנגנון לוגיקה מרכזי לדירוג וחישוב, ומערך בדיקות אוטומטיות לווידוא תקינות המערכת.

---

## 📌 מהות המערכת וקהל היעד

* **תיאור המוצר:** המערכת מיועדת לעזור לארגן ערבי משחק בצורה פשוטה, ממוקדת ואוטומטית.
* **הצורך והבעיה:** המערכת פותרת את הקושי בסינון לפי שחקנים/משך והוספת משחקים.
* **תרחיש שימוש מרכזי:** המשתמש מזין את נתוני הפתיחה וההעדפות שלו דרך התפריט, והמערכת מעבדת את הנתונים ומציגה תוצאה מחושבת ומדורגת בליווי נימוק שקוף.

---

## 🛠️ דרישות סביבה והרצה

* **גרסת Python שנבדקה:** Python 3.10 ומעלה (שימוש בספרייה הסטנדרטית בלבד, ללא התקנות חיצוניות).

### פקודת הרצה:

```bash
python main.py
```

*(במערכות Windows שבהן הפקודה `python` אינה מוגדרת, יש להשתמש ב-`py main.py`)*

### הרצת הבדיקות האוטומטיות:

```bash
python -m unittest discover -s tests -v
```

## ✨ 3 היכולות העיקריות במערכת

1. **קליטה וניהול נתונים:**
   * הוספת רשומות חדשות למאגר תוך אימות תקינות קלט (דחיית ערכים ריקים, קלטים שליליים או סוג נתונים שגוי).

2. **חיפוש וסינון מתקדם:**
   * איתור וסינון פריטים מתוך המאגר הקיים לפי קריטריונים ומגבלות שהגדיר המשתמש.

3. **לוגיקה מרכזית (חישוב / דירוג / המלצה):**
   * אלגוריתם ליבה המחשב ניקוד התאמה/דירוג, מטפל בשבירת שוויון במקרה של תוצאות זהות, ומציג הסבר ברור לתוצאה.

---

## ⚠️ מגבלות ידועות

* **אחסון בזיכרון (In-Memory):** הנתונים נשמרים בזיכרון הריצה במהלך פעולת התוכנית.
* **ממשק משתמש:** הממשק הינו טקסטואלי בלבד (CLI) הפועל דרך הטרמינל/מסוף.
* **עבודה מקומית:** התוכנית פועלת במצב אופליין מלא ואינה תלויה בשירותי ענן או חיבור לרשת.
